# CHRONYX

**Take Control of Time.**  
CHRONYX is a gamified screen-time management dashboard designed to help people build healthier digital habits.

🌐 **[Open the live demo](https://ethantjoseph7-dot.github.io/CHRONYX/)**

## Features

- **Command Center dashboard** — view today's demo screen time, daily goal, XP, and app activity.
- **App limit manager** — set daily usage limits for apps such as Discord, Epic Games, and Browser.
- **Session control** — start and stop demo sessions to record usage in the website.
- **Insights & XP** — view recent activity, XP progress, and achievements.
- **Settings** — customize your daily screen-time goal and display name.
- **Local data** — save demo settings and session data in your browser, with an option to export data.

## Important demo notes

CHRONYX v0.1 is currently a **browser-based demo**. Sessions are started manually on the website, and usage data is illustrative. It does **not** automatically detect or track time spent in other PC applications yet. Browser-local data is not connected to Discord, Epic Games, Nintendo, or any external account.

## Try it

1. Open the [CHRONYX live demo](https://ethantjoseph7-dot.github.io/CHRONYX/).
2. Start a demo session from the Dashboard.
3. Stop the session and check **Insights & XP**.
4. Try changing an app limit or your daily goal in **Settings**.
